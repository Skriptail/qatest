# Test Cases — Angular Todo App

особенности API которые влияют на тесты:
- POST всегда возвращает `{ id: 201 }` — фиксированный id от JSONPlaceholder
- PUT/DELETE принимают любой id, всегда 200
- данные не сохраняются между сессиями

## TC-01: загрузка задач при открытии страницы

тип: позитивный  
приоритет: high  
компонент: инициализация / API

**предусловие:** приложение не запущено, JSONPlaceholder доступен

**шаги:**
1. открыть localhost:4200

**ожидаемый результат:**
- список задач отображается (до 10 штук по `?_limit=10`)
- у выполненных задач чекбокс отмечен и заголовок зачёркнут

## TC-11: коллизия id при добавлении нескольких задач подряд

тип: API edge-case  
приоритет: high  
компонент: создание / удаление

**предусловие:** JSONPlaceholder всегда возвращает `id: 201` на POST

**шаги:**
1. добавить задачу "Task A" — получает id=201
2. добавить задачу "Task B" — тоже получает id=201
3. нажать Delete у "Task A"

**ожидаемый результат:**
- удалена только "Task A", "Task B" осталась 

**фактический результат (баг):**
- удаляются обе, потому что `tasks.filter(t => t.id !== 201)` убирает все с id=201

## TC-12: попытка сохранить пустой заголовок при редактировании

тип: негативный  
приоритет: medium  
компонент: редактирование / валидация  
связанный баг: BUG-003

**предусловие:** в списке есть задача

**шаги:**
1. нажать Edit у любой задачи
2. полностью очистить поле (или оставить только пробелы)
3. нажать Save

**ожидаемый результат:**
- сохранение заблокировано
- задача остаётся с исходным заголовком

**фактический результат (баг):**
- задача сохраняется с пустым заголовком
