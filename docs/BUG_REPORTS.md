| уровень | severity | priority |
|---------|----------|----------|
| critical | приложение падает / данные теряются | срочно |

## BUG-001: при удалении одной задачи удаляются все с одинаковым id

id: BUG-001  
severity: critical  
priority: high  
компонент: удаление задачи  
связанный tc: TC-11

**что происходит**  
JSONPlaceholder на каждый POST возвращает `id: 201`. если добавить несколько задач подряд у всех будет одинаковый id. при нажатии delete на одну из них удаляются все потому что фильтр смотрит по id.

**шаги воспроизведения**
1. открыть localhost:4200
2. добавить задачу "Task A"
3. добавить задачу "Task B"
4. нажать delete у "Task A"

**ожидаемый результат**  
удалилась только "Task A", "Task B" осталась

**фактический результат**  
удалились обе

**причина**  
в сервисе фильтрация идёт по id:
```typescript
this.tasks = this.tasks.filter(task => task.id !== id); // удаляет все с id=201
```

**примечание**  
это ограничение тестового JSONPlaceholder всегда возвращает id=201 на POST. в реальном приложении сервер возвращает уникальные id и баг не воспроизводится

## BUG-002: нет кнопки отмены в режиме редактирования

id: BUG-002  
severity: major  
priority: medium  
компонент: редактирование / UX

**что происходит**  
нажал edit, начал редактировать и передумал — отменить нельзя. нет кнопки cancel, нет esc. единственный выход — перезагрузить страницу.

**шаги воспроизведения**
1. нажать edit у любой задачи
2. изменить текст
3. попытаться отменить

**ожидаемый результат**  
кнопка cancel возвращает задачу к исходному тексту

**фактический результат**  
кнопки нет, изменения приходится сохранять

дополнительно: если нажать Edit на другой задаче пока одна уже редактируется — первая молча закрывается и несохранённые изменения теряются без предупреждения

**как исправить**  
добавить кнопку cancel которая отменяет редактирование и возвращает задачу к исходному тексту

## BUG-003: при редактировании можно сохранить задачу с пустым заголовком

id: BUG-003  
severity: major  
priority: medium  
компонент: редактирование / валидация

**что происходит**  
при добавлении задачи есть проверка `if (!title.trim()) return`. при редактировании её нет — можно очистить поле и сохранить пустую задачу.

**шаги воспроизведения**
1. нажать edit у любой задачи
2. полностью очистить поле
3. нажать save

**ожидаемый результат**  
сохранение заблокировано, показана ошибка

**фактический результат**  
задача сохраняется с пустым заголовком, в списке отображается пустая строка

**как исправить**  
добавить такую же проверку на пустое поле как при добавлении задачи

## BUG-004: нет обработки ошибок при недоступности API

id: BUG-004  
severity: major  
priority: medium  
компонент: все операции / обработка ошибок

**что происходит**  
все запросы (get, post, put, delete) без обработки ошибок. при потере сети пользователь ничего не видит — список просто пустой.

**шаги воспроизведения**
1. открыть devtools → network → offline
2. открыть localhost:4200

**ожидаемый результат**  
сообщение "не удалось загрузить задачи, проверьте подключение"

**фактический результат**  
пустой список без каких-либо объяснений

**как исправить**  
добавить обработку ошибок на все запросы к API и показывать пользователю понятное сообщение

## BUG-005: поле не фокусируется автоматически прс и входе в режим редактирования

id: BUG-005  
severity: minor  
priority: low  
компонент: редактирование / UX

**что происходит**  
нажал edit, поле появилось, но курсор в него не встал — нужно кликнуть вручную.

**шаги воспроизведения**
1. нажать edit у задачи
2. попробовать сразу печатать без клика по полю

**ожидаемый результат**  
курсор стоит в поле, можно сразу печатать

**фактический результат**  
фокус остался на кнопке edit

**как исправить**  
добавить автофокус на поле ввода при открытии режима редактирования

## BUG-006: нет индикатора загрузки при API-запросах

id: BUG-006  
severity: minor  
priority: low  
компонент: UX

**что происходит**  
JSONPlaceholder отвечает до 2 секунд. в это время ничего не происходит визуально — кнопки активны, спиннера нет. можно случайно нажать дважды и отправить дублирующий запрос.

**как исправить**  
блокировать кнопку на время запроса или показывать спиннер
