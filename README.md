# Angular Todo App — тестовое задание

![playwright tests](gifka.gif)

## подход

использовал Page Object Pattern — все локаторы в классе `TodoPage`, тесты не знают о вёрстке напрямую.

запросы к JSONPlaceholder перехватываются через `page.route()` и заменяются моками — тесты не зависят от сети.

## структура

```
docs/
  TEST_CASES.md       — 12 тест-кейсов
  BUG_REPORTS.md      — 6 баг-репортов
tests/
  fixtures/
    mock-tasks.ts     — тестовые данные и моки API
  pages/
    todo.page.ts      — Page Object
  todo-crud.spec.ts   — тесты CRUD
  todo-filter.spec.ts — тесты фильтрации
playwright.config.ts
```

## запуск с отчетом

```bash
npm run test:e2e:report
```

## тесты

| tc | что проверяет |
|----|---------------|
| TC-01 | загрузка задач из API |
| TC-02 | добавление через кнопку |
| TC-03 | добавление через Enter |
| TC-04 | отметка выполнения |
| TC-05 | редактирование заголовка |
| TC-06 | удаление задачи |
| TC-07 | фильтр Active |
| TC-08 | фильтр Completed |
| TC-09 | пустая задача не добавляется |
| TC-10 | задача из пробелов не добавляется |
| TC-11 | коллизия id при нескольких добавлениях |
| TC-12 | пустой/пробельный заголовок при редактировании |

## баги

| id | описание | severity |
|----|----------|----------|
| BUG-001 | удаление одной задачи удаляет все с id=201 | critical |
| BUG-002 | нет кнопки отмены редактирования | major |
| BUG-003 | можно сохранить задачу с пустым заголовком | major |
| BUG-004 | нет обработки ошибок API | major |
| BUG-005 | поле не фокусируется при редактировании | minor |
| BUG-006 | нет индикатора загрузки | minor |

## сложности

JSONPlaceholder всегда возвращает `id: 201` на POST — из-за этого все добавленные задачи получают одинаковый id и при удалении одной удаляются все. TC-11 намеренно воспроизводит этот баг.
